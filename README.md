# Personal Jarvis Blueprint

A 15-slide web presentation on how to build a personal AI chief of staff ("Jarvis") that knows me, tracks my work commitments, and supports my path to a CTO or CEO role.

## What's inside

- What the agent does: six specialist capabilities
- A day with the agent running
- Logical architecture (six layers plus a governance rail)
- Solution architecture (devices, private cloud tenant, model provider, connected sources)
- Data flow: a learn loop and an act loop
- Data sources, with phase and risk for each
- What I need to provide: profile, writing samples, promotion evidence, career targets
- CTO / CEO readiness model
- Autonomy ladder and guardrails
- Build options and a 12-week roadmap

## View it

Open `index.html` in any browser, or visit the GitHub Pages link once it's enabled.

Use the arrow keys or the buttons at the bottom right to move between slides. The page follows your system's light or dark mode.

## Note

This is planning guidance, not legal advice. Check your employment contract and local data-protection rules before connecting work systems to a personal tool.
